Two details made explicit per review
1. Analog-island isolation claim - measurable definition
Previous claim ">40dB attenuation across 500kHz-2MHz SMPS band" lacks measurement nodes and calculation.


Ferrite bead attenuation depends on:


* Its impedance Z(f) across 500kHz-2MHz, not just 600Ω @100MHz spec point
* Surrounding source impedance (3V3_RAW from Pico SMPS) and load impedance (3V3_A island C4 10uF + C5/C6 100nF + U1 + divider)
* Capacitor network forming pi-filter: C4 bulk + FB1 + C5/C6


Exact definition to be used for pass/fail:


* Measurement nodes: V_RAW = 3V3_RAW before FB1 (Pico side), V_A = 3V3_A after FB1 (analog island side, at C4 pad)
* Source: Pico internal SMPS switching at 500kHz-2MHz (RT6150), or external injection via VNA/spectrum analyzer with 50Ω source for characterization
* Load: Actual analog island load (U1 TLV9062 + R4/R5 divider + C4/C5/C6) or 50Ω termination for VNA, state which
* Attenuation calculation: A(f) = 20*log10(|V_RAW(f)| / |V_A(f)|) in dB, measured at 500kHz, 1MHz, 1.5MHz, 2MHz
* Pass criterion: A(f) >40dB for all f in [500kHz, 2MHz] with stated source/load
* Method: VNA S21 with injection cap, or spectrum analyzer with near-field probe + direct probe, document calibration, bandwidth, averaging
* Evidence label: PHYSICAL_BENCH_VALIDATION_PENDING until VNA data with nodes and calculation documented
* Note: Solid L2 GND unbroken is assumed; if milled slot used, return-current detour increases loop and may degrade isolation - must not cross signals over slot
2. Calibration LUT - exact contract
Note specifies 33 quantiles and 66-byte LE binary, but parser and firmware must agree on full contract. Monotonic table alone does not prove mapping produces statistically uniform output.


Contract:


* Size: Exactly 33 points, no more no less
* Integer width: uint16_t, 0-4095 (12-bit ADC range)
* Byte order: Little-endian if binary representation used (for offline analysis only - no host dump in current protocol)
* Endpoint handling: lut[0] = min quantile (0/32), lut[32] = max quantile (32/32), inclusive. Mapping: adc <= lut[0] => u=0.0, adc >= lut[32] => u=1.0
* Duplicate quantiles: If hi == lo for interval idx (flat region), t=0, u = idx/(32). No division by zero
* Monotonicity: Non-decreasing, lut[i] <= lut[i+1] for all i, 0<=lut[i]<=4095, fails closed if violated
* Interpolation: Piecewise-linear between quantiles. idx = searchsorted(lut, adc, side='right')-1, clamped 0..31, lo=lut[idx], hi=lut[idx+1], denom=hi-lo, t=(adc-lo)/denom if denom>0 else 0, u=(idx+t)/32
* No silent linear-scaling substitute: Gaussian does NOT become uniform via linear scaling, must use LUT
* Verification: Test 1.3 KS D<0.02 on u stream, plus moments mu 0±0.01 sigma 0.577±0.02 kurt -1.2 on [-1,1] mapping. KS pass proves mapping produces uniform by construction, monotonic alone does not
* Evidence labels: LUT generation = MODEL_EXECUTION (firmware) or PHYSICAL_BENCH_VALIDATION_PENDING (real hardware), KS on u = STATISTICAL_RESULT, uniformity claim = PHYSICAL_BENCH_VALIDATION_PENDING until hardware data
* Current status: Format specified, actual table contents and model execution still require evidence via Test 1.3, no host READ_LUT unless added to Protocol v1.1
